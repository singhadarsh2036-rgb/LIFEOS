# LIFEOS

AI-powered family operations platform.

## Vision

LIFEOS is a centralized platform designed to help families manage important aspects of their daily lives, assets, documents, travel and recurring responsibilities.

## Core Modules

- Home & Assets
- Vehicle Management
- Document Management
- Travel Management
- Smart Reminders
- Family Management
- AI Assistant

## Tech Stack

- Backend: Java + Spring Boot
- Database: PostgreSQL
- Mobile: React Native
- AI: AI API
- Version Control: Git + GitHub
